# 📸 Engagement Photo Booth

تطبيق ويب بيشتغل على أي تابلت (iPad أو Android):
الضيف يتصور ← يكتب اسمه وكلمة للعرسان ← بيتعمل له كارت شيك (الصورة + الكلمة + الاسم + أسماء العرسان والتاريخ).
كل حاجة بتتحفظ **على التابلت نفسه** وبيشتغل **من غير إنترنت**، وفي آخر اليوم بتصدّر كل الصور في ملف ZIP واحد.

---

## 1) ارفع التطبيق على النت (مرة واحدة — مجاناً)

الكاميرا في المتصفح لازم لينك `https`، فلازم ترفع الفولدر ده:

**GitHub Pages (الأضمن):**
1. https://github.com/new ← اسم الـ repo: `photobooth` ← **Public** ← Create repository.
2. دوس **uploading an existing file** ← اسحب **كل الملفات اللي جوه الفولدر** (مش الفولدر نفسه) ← **Commit changes**.
3. **Settings** ← **Pages** ← Branch: `main` / `(root)` ← **Save**.
4. بعد دقيقة هيظهر لينك زي `https://اسمك.github.io/photobooth/` — ده لينك البوث.

(بديل: Netlify أو Cloudflare Pages — أي استضافة static بـ https تنفع.)

## 2) جهّز التابلت

### iPad
1. افتح اللينك في **Safari** وانت على النت.
2. زرار المشاركة ⬆️ ← **Add to Home Screen**.
3. افتح التطبيق **من الأيقونة** (مش من Safari) ← اسمح بالكاميرا.
4. هتفتح لك الإعدادات أول مرة: اكتب أسماء العرسان، التاريخ، وغيّر الرقم السري (الافتراضي `1234`) ← **Save settings** ← **Back to booth**.

> ⚠️ على الآيباد، الصور بتتخزن جوه الأيقونة دي. **متمسحش الأيقونة من الهوم سكرين** قبل ما تصدّر الصور، واستخدم الأيقونة دايماً مش Safari.

### Android
Chrome ← افتح اللينك ← القائمة ⋮ ← **Install app / Add to Home screen** ← افتحه من الأيقونة.

## 3) قبل الحفلة

- اعمل **بروفة**: اتصور 2-3 صور، صدّر ZIP، اتأكد إنه تمام، وبعدين امسحهم من **Delete all photos**.
- افتح التطبيق مرة وانت على النت يوم الحفلة الصبح (عشان الخطوط تتخزن) — بعد كده النت مش مهم.
- **iPad:** Settings ← Display & Brightness ← Auto-Lock ← **Never**.
- **iPad:** فعّل **Guided Access** (Settings ← Accessibility ← Guided Access) واضغط زرار الباور 3 مرات وانت في التطبيق عشان محدش يخرج منه.
- **Android:** فعّل Screen pinning.
- خلّي الشاحن متوصل، وحط التابلت على ستاند في مكان منوّر.

## 4) لوحة التحكم

**اضغط 5 مرات بسرعة في الركن الشمال فوق** ← اكتب الرقم السري.

من هناك تقدر:
- تغيّر الأسماء / التاريخ / اللون / الرقم السري.
- تشوف كل الصور وتمسح أي صورة.
- **تصدّر كل حاجة**.

لوحة التحكم بتقفل لوحدها بعد 3 دقايق من غير استخدام، وشاشة الضيوف بترجع للبداية لوحدها لو حد ساب الصورة في النص.

## 5) آخر اليوم — خد الصور

لوحة التحكم ← **Export all photos (ZIP)** ← بعد ما يخلص:
- **Share / AirDrop / Save to Files** (الأفضل على الآيباد — ابعته AirDrop لموبايلك أو اللابتوب)، أو
- **Download**.

💡 اعمل نسخة احتياطية كده في نص الحفلة كمان، احتياطي.

### جوه الـ ZIP
| الملف | فيه إيه |
|---|---|
| `cards/` | الكروت النهائية (صورة + كلمة + اسم) — جاهزة للطباعة أو النشر |
| `photos/` | الصور الأصلية من غير كتابة، بجودة كاملة |
| `guestbook.csv` | جدول: رقم، وقت، اسم، الكلمة (يتفتح في Excel بالعربي) |
| `guestbook.html` | صفحة حلوة فيها كل الكروت والكلام — افتحها على اللابتوب |

---

## الملفات
- `index.html` / `style.css` / `app.js` — التطبيق
- `sw.js` — بيخلّيه يشتغل أوفلاين
- `manifest.webmanifest` + الأيقونات — عشان يتثبت على الهوم سكرين

لو عدّلت أي ملف بعد ما رفعته، زوّد رقم الإصدار في `sw.js` (مثلاً `photobooth-v2` ← `photobooth-v3`) وارفع تاني، وافتح التطبيق مرتين عشان التحديث يوصل.
